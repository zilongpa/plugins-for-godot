# Apple plugins for Godot

## Overview

This repository contains plugins for the
[Godot](https://godotengine.org/) game engine. These plugins help to create new content or migrate existing projects to Apple platforms using the Godot engine's tools and features. There are two plugins available. 

## RealityKit

The plugin in [godotrealitykit](./godotrealitykit/README.md)
renders Godot games with [RealityKit](https://developer.apple.com/documentation/realitykit/) on visionOS. The plugin supports immersive experiences as well as a volumetric camera mode to bring your scenes to life in the shared app space.

![](godotrealitykit/documentation/screenshots/DogWalk.jpg)

## PHASE

The plugin in [godotphase](./godotphase/README.md)
brings Apple's [PHASE](https://developer.apple.com/documentation/phase) spatial audio framework to Godot,
with support for macOS, iOS, tvOS, and visionOS.
